Wikipedia Edit History Colors

Colors every word of a Wikipedia article by when it was added, and lets you triple-click any word to see the section as it looked in the edit that added it.

Drag this button to your bookmarks bar to save it as a bookmarklet, then click it on any Wikipedia article:

Wikipedia Edit History Colors

If your browser refuses long bookmark URLs, use this loader version instead (it fetches the script from this site): Wikipedia Edit History Colors (loader)

How to read it

oldest (black / red)newest (violet / white)
  • The ramp runs red → orange → yellow → green → blue → violet from the article's first edit to its latest one.
  • Lightness climbs monotonically from black to white along the ramp, so the ordering is still readable in grayscale or with any form of color blindness. Text sits on the color in black or white for contrast. The Mono button drops the hue entirely, Ink colors the letters instead of the background, and ⇄ reverses the direction.
  • Spaces are never colored. Words that only exist in the rendered page (infobox labels, navigation text, anything generated by a template) get a dotted underline instead of a color.
  • Hover a word for the date range it was added in. Triple-click or triple-tap a word to pinpoint the exact revision and open a 60%-inset popup showing that section as it was then, scrolled so the word is centered and highlighted. Esc or the backdrop closes it.
  • Click the bookmarklet again (or the ✕ in the legend) to restore the page.

How it works

Only Wikipedia's own API is used, so it works on every language edition. The article's history is sampled at evenly spaced points in time (plus extra samples where most of the text landed); each word of the current wikitext is dated to the earliest sample that already contains it together with a neighbouring word, then the rendered page is aligned back to the wikitext to paint it. Triple-clicking runs a binary search between the two surrounding samples to find the exact edit.
