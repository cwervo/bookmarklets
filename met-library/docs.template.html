Watson Library, but for your phone

A bookmarklet that wraps library.metmuseum.org (Watsonline) in a modern search, bag and request flow. Launch it from the iOS Shortcuts share sheet or a Safari bookmark.

🔍 SearchBig search box, Everything / Title / Author / Subject, recent searches, endless scroll.
📖 RecordsClean detail sheet: copies, call numbers, status, subjects, online links.
👜 Bag → CheckoutCollect books, then request them all in one guided flow. Watson pages them for your visit.
👤 AccountSign in, see checkouts and holds, sign out — inside the same sheet.

1 · Install as an iOS Shortcut

iOS Shortcuts can run JavaScript on the page that's open in Safari. Set it up once, then it's one tap from the share sheet.

  1. Open the Shortcuts app and tap + to create a new shortcut.
  2. Add the action Run JavaScript on Web Page (search for it; it's under Safari).
  3. Delete the sample code inside the action and paste the script below.

    Show the script
  4. Tap the shortcut's name at the top → Rename it “Watson Library”, then open its details (ⓘ) and turn on Show in Share Sheet. Under Share Sheet Types keep only Safari web pages.
  5. In Safari, open library.metmuseum.org, tap the Share button and choose Watson Library.

Run it from any other page and it simply sends you to Watsonline first; run it again once the page has loaded. You can also download the script as shortcut.js.

How it works

The script runs on library.metmuseum.org, so it can fetch Watsonline's own HTML pages (same origin) and re-render them as a clean, phone-sized interface on top of the site. Nothing is proxied through a third party.

  • Search uses Watsonline's keyword search (with t:, a:, d: qualifiers for title, author, subject) and parses the brief-citation rows.
  • Checkout is Watsonline's own Request flow. Each item in your bag opens its request form inside a sheet with mobile-friendly styling; you sign in once (last name + last 6 digits of your library barcode), pick a pickup location if asked, submit, and the app advances to the next item when it sees the confirmation.
  • Your bag, recent searches and request history live in Safari's local storage for library.metmuseum.org — on your device only.
  • Cover images come from Open Library when a record lists an ISBN; that is the only third-party request.

Watson Library is a non-circulating research library: “checkout” here means having books paged to the reading room for your visit. You need a Watson Library card (issued at the desk, visitors 18+) to place requests.

Watsonline runs on Innovative's Sierra WebPAC. The app targets that catalog's standard URL and markup conventions with several fallbacks, and when a page can't be parsed it always offers an “Open in Watsonline” link. If the Met changes their catalog templates, open an issue.
